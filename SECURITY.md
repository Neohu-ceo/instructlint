# Security policy

## Supported versions

Only the latest minor release receives security fixes during the alpha period.

## Reporting

Please use GitHub's private vulnerability reporting for anything that could make
InstructLint execute repository content, leak local data, or produce a dangerous
autofix. Do not open a public issue until a fix is available.

InstructLint is designed as a read-only analyzer. It does not execute discovered
commands and does not send repository content over the network.
